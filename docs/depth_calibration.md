# 下针深度自动标定现场操作说明（第一阶段：160 料盘多点对焦测试）

## 1. 用途与范围

本流程用于评估**主相机对焦峰定 Z 的重复性与料盘平面度**，验证主相机（8mm 定焦镜头，工作距约 100mm）是否满足下针深度自动标定误差预算（总误差 ≤ 0.05 mm，对焦环节预算约 0.02 mm）。

- **当前已实现**：功能码 `160`（料盘多点 Z 向对焦扫描，完成回 `161`）。
- **后续阶段（本阶段不实现）**：功能码 `170/171`（标定尖对焦）、`180/181`、`190/191`（工具尖贴近标定尖）；收到上述功能码一律回 `999`（`"下针深度标定 170/180/190 尚未实现"`）。

### 坐标与安全约定
- 模组 Z 行程为 `[-15, 0]` mm：`Z−` 向下（靠近料盘），`Z+` 向上（远离料盘）。
- 两把工具与主相机共用 Z 轴，相机下降时工具尖同步下降，**必须配置 `depth_calibration.camera_z_min_mm`**。
- 现场已于 11-26 核定 `camera_z_min_mm: -12.0`。程序默认缺省值为 `null`；若置空未配置，收到 `160` 直接回 `999` 拒绝启动。每次下发坐标及到位检查均强制校验 `Z ≥ camera_z_min_mm` 且 XYZ 在 `travel` 内。
- 扫描期间主相机必须关闭自动曝光（固定曝光）；若曝光自动开启或中途变化，立即报错回 `999`。

## 2. 160/161 协议与自动流程

开始前：将 V2 菲林片平整固定在料盘上；完成主相机标定（`camera.yaml` 有效且非占位）；将主相机移到菲林任意靶点上方初始 Z 高度（推荐在焦点附近，使上下 3mm 能覆盖清晰峰），确认固定曝光且无过曝/过暗。

1. **发起会话（PLC 发 160）**：
   - PLC 写入 `40904 = 160` 并更新 `Task_ID`（`40903`），模式切为 `下针深度标定中`。
   - 后续每次需要移动相机，PC 将目标 `(X, Y, Z)` 写入 **`40942–40946`** 并回 **`160`**；PLC 到位后再发 **`160`**（新 `Task_ID`）推进下一步。
   - **不检查也不回显 `40905`**。
2. **第 1 步：测点居中**：
   - 读稳定实时坐标（6 次 / 0.5 s 极差 ≤ 0.02 mm 取均值），连拍 3 帧取中位图，用菲林靶点检测识别离画面中心最近的环心。
   - 若初始位置不在计划首点，先按布局毫米差移向计划测点；若当前靶点已在默认 5 点计划内，优先从当前靶点开始测。
   - 重复计算平移量把环心拉到画面中心，直到偏差 `≤ center_tol_px`（默认 `15 px`），最多 `center_max_iter`（默认 `5`）轮。
   - 居中后在环心周围截取固定正方形 ROI（边长 `roi_mm` 默认 `8 mm`，按当前像素尺度换算），整个扫描过程 XY 固定、不再重新检测。
3. **第 2 步：粗扫（`coarse`）**：
   - 先抬升到 `min(Z0 + coarse_range_mm, travel_z_max)`，再以 `coarse_step_mm`（默认 `0.2 mm`）**逐步向下**扫到 `max(Z0 - coarse_range_mm, camera_z_min_mm)`。
   - 每步到位稳定后拍 `frames_per_step`（默认 `3`）帧计算清晰度取中位。
   - 当越过当前最大值且清晰度 `< defocus_ratio`（默认 `0.3`）× 最大值并连续 2 步时，提前结束粗扫。若最大值出现在最高或最低边界步，报错回 `999`。
4. **第 3 步：细扫（`fine`，重复 `repeats_per_point` 次，默认 3 次）**：
   - 默认 `fine_range_mode: auto` 时，根据粗扫拟合出的 `FWHM_粗扫` 自适应计算细扫半宽与步距（防止 `FWHM` 达到 1–3 mm 时固定 ±0.6 mm 只扫到峰顶平坦段导致高斯拟合退化）：
     - `细扫半宽 = clamp(fine_range_factor × FWHM_粗扫, fine_range_min_mm, fine_range_max_mm)`（默认 `0.75 × FWHM`，限制在 `[0.3, 3.0] mm`）；
     - `细扫步距 = clamp(2 × 细扫半宽 / fine_steps_target, fine_step_min_mm, fine_step_max_mm)`（默认目标 40 步，步距限制在 `[0.02, 0.10] mm`）。
     - 若粗扫拟合失败或 `FWHM` 无效，自动回退 `fixed`（`fine_range_mm` / `fine_step_mm`）并在记录和界面注明。
   - 若为 `fine_range_mode: fixed`，则直接使用 `fine_range_mm`（默认 `0.6`）和 `fine_step_mm`（默认 `0.02`）。
   - 上下边界均受 `camera_z_min_mm` 与 `travel.z` 约束；发生截断时在记录与界面提示。
   - 每次先上到 `min(Z_peak_coarse + 半宽 + overshoot_mm, travel_z_max)`，再**单向向下**扫到 `max(Z_peak_coarse - 半宽, camera_z_min_mm)`。抬升阶段不采图，**只使用向下那一趟的数据**（消除丝杠反向间隙），且实测 Z 必须严格递减。
5. **第 4 步：峰位拟合、质量门与峰位全幅留档**：
   - 对每条细扫曲线取 `≥ 50%` 最大值的点，对 `log(清晰度)` 做二次多项式高斯拟合，输出 `Z_peak`、`FWHM`、`R²`；同时计算半高宽中点法峰位作对照。
   - **拟合质量门**：参与拟合的点在峰两侧各须 `≥ 5` 个，且最低参与点须 `≤ 0.6 × 峰值`（确认覆盖到曲线下降段）；否则该次细扫标记为 **“拟合点不足”**，在可行性结论中单列且不计入“满足”。
   - 该点 3 次细扫完成后，将相机移到均值 `Z_peak` 拍一张全幅参考图留档。
6. **第 5 步：多点与平面判定（`161` 结束）**：
   - 默认按菲林四角 + 中心测 5 个靶点；下一靶点相机坐标按布局毫米差推算，Z 沿用上一点 `Z_peak`。
   - 5 点测完后拟合平面 `z = ax + by + c`：若最大 `|残差| ≤ plane_tol_mm`（默认 `0.02 mm`），直接回 **`161`** 完成；
   - 若最大 `|残差| > plane_tol_mm`，自动加测四条边中点靶点（最多加到 `max_points`，默认 `9` 点）再拟合一次，输出加测后残差变化说明，随后回 **`161`**。

- 会话中点击界面 **【放弃本次标定】**，下一个 PLC 请求回 `999` 并结束会话。
- 会话中收到非 `160` 功能码，或在其他业务模式中收到 `160`，均回 `999`。

## 3. 主要配置项说明（`config/nest_clear.yaml` → `depth_calibration`）

未在 YAML 中写出的字段均采用 `src/nest_clear/depth_config.py` 中的程序默认值：

| 配置项 | 默认值 / 当前值 | 含义与调整说明 |
|---|---|---|
| `camera_z_min_mm` | 当前 `-12.0`（程序默认 `null`） | **安全 Z 下限（mm）**；11-26 用户核定为 `-12.0`，为空时拒绝 `160` |
| `center_tol_px` | `15.0` | 测点居中允许的最大圆环中心像素偏差（px） |
| `center_max_iter` | `5` | 单点居中最大迭代次数，超过回 `999` |
| `roi_mm` | `8.0` | 清晰度计算 ROI 边长（mm），围绕居中后环心固定裁剪 |
| `coarse_range_mm` | `3.0` | 粗扫相对初始 `Z0` 的半范围（mm） |
| `coarse_step_mm` | `0.2` | 粗扫向下步距（mm） |
| `defocus_ratio` | `0.3` | 粗扫提前结束离焦阈值（低于当前最大清晰度该比例连续 2 步即停） |
| `fine_range_mode` | `auto` | 细扫范围模式：`auto`（按粗扫 FWHM 自适应）或 `fixed`（固定 `fine_range_mm` / `fine_step_mm`） |
| `fine_range_factor` | `0.75` | `auto` 模式下 `细扫半宽 = fine_range_factor × FWHM_粗扫` 的比例系数 |
| `fine_range_min_mm` / `fine_range_max_mm` | `0.3` / `3.0` | `auto` 模式下细扫半宽的上下限夹紧范围（mm） |
| `fine_steps_target` | `40` | `auto` 模式下每次细扫的目标步数（用于反算步距） |
| `fine_step_min_mm` / `fine_step_max_mm` | `0.02` / `0.1` | `auto` 模式下细扫步距的上下限夹紧范围（mm） |
| `fine_range_mm` | `0.6` | `fixed` 模式或粗扫拟合失败回退时的细扫半范围（mm） |
| `fine_step_mm` | `0.02` | `fixed` 模式或回退时的细扫向下步距（mm） |
| `overshoot_mm` | `0.3` | 细扫顶部换向过冲余量（mm），用于避开反向间隙 |
| `repeats_per_point` | `3` | 每个靶点的细扫重复次数 |
| `frames_per_step` | `3` | 每个 Z 台阶采图帧数（取各清晰度指标中位数） |
| `metric` | `tenengrad` | 主清晰度指标：`tenengrad` / `laplacian` / `brenner`（均做均值平方亮度归一） |
| `peak_method` | `gauss` | 主拟合方法：`gauss`（对数二次拟合）/ `half_height`（半高宽中点法） |
| `plane_tol_mm` | `0.02` | 初始 5 点平面最大残差触发加测门限（mm） |
| `repeat_range_tol_mm` | `0.02` | 可行性判定的重复性门限（mm），与最大极差及最大标准差比较 |
| `max_points` | `9` | 触发加测后的最大总测点数（5 至 9） |
| `point_order` / `extra_points` | `null` | 可选覆盖初始 5 点与加测 4 点标签列表（`T00`–`T31`） |
| `settle_samples` / `settle_window_s` / `jitter_tol_mm` | `6` / `0.5` / `0.02` | PLC 实时坐标稳定窗口采样参数 |
| `position_tolerance_mm` | `0.01` | 相机 Z 步进到位核对容差（mm） |

## 4. 如何判读界面曲线、结果表与可行性结论

界面切至 **【下针深度标定】** 页后，重点查看以下四块区域：

1. **清晰度曲线图**：
   - 横轴为实测 `PLC Z (mm)`，纵轴为亮度归一化清晰度；每个靶点独立一张子图。
   - **灰线（带圆点）** 为粗扫曲线，应呈单峰钟形；**蓝/绿/橙实线** 分别为第 1/2/3 次细扫曲线，**红色/彩色竖线** 标出拟合峰位 `Z_peak`。
   - 理想情况：3 条细扫曲线几乎重合、峰部光滑对称、竖线基本重叠在一条线上。
2. **各测点结果表**：
   - 查看每点 `细扫1/2/3 Z`、`极差`、`标准差`、`FWHM`（半高宽，反映镜头景深与清晰区宽度）和 `R²`（高斯拟合优度，越接近 1 越理想）。
   - 若某点 `R²` 明显偏低或 `FWHM` 过大，需检查该点照明反光或扫描范围是否只覆盖了单侧。
3. **平面拟合结果与加测说明**：
   - 查看平面方程 `z = ax + by + c`、最大 `|残差|` 与倾斜量（`mm/100mm`）。
   - 若最大 `|残差| > 0.02 mm` 触发加测至 9 点，对照 **"加测后残差下降 / 不变 / 增大"**：
     - **加测后残差仍与初测相当或呈系统曲面**：多为料盘本身存在局部起伏/弯曲；
     - **某单点残差突兀且其它点很平**：多为该点测量误差、菲林翘起或异常污渍。
4. **可行性结论栏**：
   - 汇总全部测点细扫 `Z_peak` 的 **最大极差** 与 **最大标准差**，与 `repeat_range_tol_mm`（默认 `0.02 mm`）比较。
   - 若存在任意一次细扫未通过质量门（峰两侧拟合点不足 5 个或最低参与点 `> 0.6 × 峰值`），可行性结论中将单列 **“拟合点不足 x/y 次（不计入满足）”**，整体判定为不满足。
   - 满足门限且无拟合点不足时显示绿色：**"对焦重复性满足下针深度标定误差预算（总 0.05mm，对焦环节约 0.02mm）"**；不满足时显示红色提示，需结合 `FWHM` 和现场指标（对比 `curves.csv` 中三种指标）决定是否调小光圈、加高工作倍率或改用其他定 Z 方式。

## 4.5 每测点往返次数与总时长估算（按每步 1.5 s）

在 `fine_range_mode: auto` 默认参数下（`coarse_range_mm=3.0`、`coarse_step_mm=0.2`、`defocus_ratio=0.3`、`repeats_per_point=3`、`fine_steps_target=40`）：

- **居中**：每点通常 `1–3` 轮（按典型 `2` 次往返计）。
- **粗扫**：最大 `31` 步；因 `defocus_ratio=0.3` 提前离焦停止，在预计 `FWHM = 1–3 mm` 时通常需 `20–28` 次往返。
- **细扫（3 次）**：
  - `FWHM = 0.5 mm` → 半宽 `0.375 mm`、步距 `0.020 mm`：`39` 采样 + `1` 抬升 = `40 × 3 = 120` 次往返；
  - `FWHM = 1.0–2.67 mm`（典型 `2.0 mm` 半宽 `1.50 mm`、步距 `0.075 mm`）→ `41` 采样 + `1` 抬升 = `42 × 3 = 126` 次往返；
  - `FWHM = 3.0 mm` → 半宽 `2.250 mm`、步距 `0.100 mm`（触及步距上限）：`46` 采样 + `1` 抬升 = `47 × 3 = 141` 次往返；
  - `FWHM = 4.0 mm` → 半宽 `3.000 mm`（触及半宽上限）、步距 `0.100 mm`：`61` 采样 + `1` 抬升 = `62 × 3 = 186` 次往返。
- **峰位全幅留档**：每点 `1` 次往返。

因此，针对现场主相机预计 `FWHM = 1–3 mm` 的典型工况：
- **单点预计往返次数**：`~149–172 次`（典型约 `155 次`）；
- **单点预计时长**（按 `1.5 s / 步`）：`~224–258 s`（约 `3.7–4.3 分钟/点`）；
- **5 点总计**：`~745–860 次` 往返，约 **`19–21.5 分钟`**；
- **若触发加测至 9 点**：`~1340–1548 次` 往返，约 **`33.5–38.7 分钟`**。

## 5. 记录文件位置与内容

每次会话自动保存到 `runs/<日期>/depthcal/<会话>/`：
- `curves.csv`：每步原始记录（`label, pass, direction, z_cmd, z_actual, tenengrad, laplacian, brenner`）。
- `roi/*.png`：每步所选中位帧的 ROI 裁剪图。
- `<标签>_center.png` / `<标签>_peak.png`：每个靶点居中后与均值峰位处的全幅原图。
- `fits.json`：每个测点的 3 种清晰度拟合结果（含高斯与半高宽对照）及可行性汇总。
- `plane.json`：初测 5 点与加测后平面方程、各点残差、倾斜量及残差变化判定。
- `plc.jsonl` & `session_record.json`：全部 PLC 请求/应答序列、配置快照、固定曝光值与结束诊断。

## 6. 常见失败原因与错误码对照

| 错误码 | 现象 | 位置 | 现场排查建议 |
|---|---|---|---|
| `DEPTH-Z-MIN` | 未配置相机 Z 下限 | `160` 会话启动 | 核查两把工具与料盘间隙后在 `config/nest_clear.yaml` 填写 `depth_calibration.camera_z_min_mm` |
| `DEPTH-Z-LIMIT` | 目标或实测 Z 低于安全下限 | 下发/到位安全守卫 | 提高初始 Z，或重新评估工具间隙与 `camera_z_min_mm` |
| `DEPTH-UNIMPLEMENTED` | 收到 `170/171/180/181/190/191` | PLC 请求 | 本阶段只使用 `160`，勿发后续阶段功能码 |
| `DEPTH-MODE` | 当前模式不允许或会话中收到非 `160` | PLC 请求 | 空闲态从 `160` 发起；会话中只连续发 `160` |
| `DEPTH-CALIBRATION` | 缺少有效主相机标定 | `160` 会话启动 | 先通过 `80` 完成主相机标定（非占位文件） |
| `DEPTH-EXPOSURE` | 未关闭自动曝光或扫描中曝光改变 | 采图前置/采图校验 | 在相机配置中固定曝光并关闭自动曝光 |
| `DEPTH-TARGET` | 未识别到菲林靶点或靶点标签跳变 | 居中识别 | 检查初始位置是否正对菲林、菲林旋转方向、光照与初始焦距 |
| `DEPTH-CENTER` | 达到居中上限仍未进入 `center_tol_px` | 居中循环 | 检查主相机标定投影精度、PLC XY 到位精度与 `center_tol_px` |
| `DEPTH-ROI` | 固定 ROI 超出图像边界 | 居中结束取 ROI | 减小 `roi_mm` 或检查像素比例尺与居中性 |
| `DEPTH-PEAK-BOUNDARY` | 对焦峰出现在粗扫/细扫边界或不足 3 步 | 粗扫 / 细扫 | 根据提示方向（`Z+` 向上或 `Z−` 向下）调整初始 `Z0` 或扫描范围 |
| `DEPTH-DIRECTION` | 细扫/粗扫实测 Z 未严格下降 | 扫描步进 | 检查 `fine_step_mm`、PLC Z 到位精度与 `position_tolerance_mm` |
| `DEPTH-FINE-RANGE` | Z 行程不足以完成换向过冲与细扫 | 细扫规划 | 调整初始 Z、缩小 `fine_range_mm` / `overshoot_mm` 或确认 Z 行程 |
| `DEPTH-FIT` | 高斯或半高宽峰拟合失败 | 细扫拟合 | 检查细扫范围是否覆盖半高宽两侧，尝试更换 `metric` 或曝光 |
| `DEPTH-PLANE` | 测点共线无法拟合平面 | 平面判定 | 确保 `point_order` 包含二维分散靶点 |
| `DEPTH-SETTLE` / `DEPTH-ARRIVAL` | 实时坐标未稳定或到位超差 | 坐标采样 | 检查 PLC 到位信号时序、机械振动、`jitter_tol_mm` 与 `position_tolerance_mm` |
| `DEPTH-ABORTED` | 操作员在界面点击【放弃本次标定】 | 会话控制 | 确认放弃后可重新发 `160` 开始新测试 |
