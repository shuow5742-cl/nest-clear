# 下针深度自动标定现场操作说明（第一阶段：160 料盘多点对焦测试）

## 1. 用途与范围

本流程用于评估**主相机对焦峰定 Z 的重复性与料盘平面度**，验证主相机（8mm 定焦镜头，工作距约 100mm）是否满足下针深度自动标定误差预算（总误差 ≤ 0.05 mm，对焦环节预算约 0.02 mm）。

- **当前已实现**：功能码 `160`（料盘多点 Z 向对焦扫描，完成回 `161`）。
- **后续阶段（本阶段不实现）**：功能码 `170/171`（标定尖对焦）、`180/181`、`190/191`（工具尖贴近标定尖）；收到上述功能码一律回 `999`（`"下针深度标定 170/180/190 尚未实现"`）。

### 坐标与安全约定
- 模组 Z 行程为 `[-15, 0]` mm：`Z−` 向下（靠近料盘），`Z+` 向上（远离料盘）。
- 两把工具与主相机共用 Z 轴，相机下降时工具尖同步下降，**必须配置 `depth_calibration.camera_z_min_mm`**。
- 现场已于 11-26 核定 `camera_z_min_mm: -12.0`。程序默认缺省值为 `null`；若置空未配置，收到 `160` 直接回 `999` 拒绝启动。每次下发坐标及到位检查均强制校验 `Z ≥ camera_z_min_mm` 且 XYZ 在 `travel` 内。
- 扫描期间主相机必须关闭自动曝光（固定曝光）。每个测点居中完成后、开始粗找前，按页面配置的【自动】或【手动】模式确定并**锁定该点曝光**；该点整个粗找与细测期间若曝光被外部改动，立即报错回 `999`。会话结束时（无论 `161` 完成、`999` 失败、放弃或中断），自动恢复会话前主相机曝光与 `ExposureAuto` 原模式，恢复失败则写 `error` 事件并在诊断中提示重启程序。

## 2. 160/161 协议与自动流程

开始前：将 V2 菲林片平整固定在料盘上；完成主相机标定（`camera.yaml` 有效且非占位）；将主相机移到菲林任意靶点上方初始 Z 高度。

1. **发起会话（PLC 发 160）**：
   - PLC 写入 `40904 = 160` 并更新 `Task_ID`（`40903`），模式切为 `下针深度标定中`。
   - 后续每次需要移动相机，PC 将目标 `(X, Y, Z)` 写入 **`40942–40946`** 并回 **`160`**；PLC 到位后再发 **`160`**（新 `Task_ID`）推进下一步。
   - **不检查也不回显 `40905`**。
2. **第 1 步：测点居中与每点曝光锁定**：
   - 采用非阻塞滑动窗口持续读取 PLC 实时坐标（按 `settle_window_s / (settle_samples - 1)` 间隔采样，取最近 `settle_samples` 个样本，默认 `6` 次 / `0.5 s`）。
   - **到位判据**：窗口每轴极差 `≤ jitter_tol_mm`（默认 `0.02 mm`）**且**窗口均值与目标 `expected` 每轴偏差 `|均值 − expected| ≤ position_tolerance_mm`（默认 `0.01 mm`）时立即取均值继续（首次 `160` 尚无 `expected` 时只按极差判稳）。
   - 若超时 `arrival_timeout_s`（默认 `2.0 s`）仍未满足，则取**最后一个窗口的均值**作为实测坐标 `actual` 照常继续流程（**不因到位超差或未稳定回 `999`**），并将本次异常（`超差` / `未稳定` / `超差+未稳定`）记入 `arrivals.csv` 与 `events.jsonl`（`depthcal_arrival_warning`）。仅在读取 PLC 失败、坐标非有限数或实测坐标超出深度行程 / 低于 `camera_z_min_mm` 时回 `999`。
   - 连拍 3 帧取中位图，用菲林靶点检测识别离画面中心最近的环心。
   - 若初始位置不在计划首点，先按布局毫米差移向计划测点；若当前靶点已在默认 5 点计划内，优先从当前靶点开始测。
   - 重复计算平移量把环心拉到画面中心，直到偏差 `≤ center_tol_px`（默认 `15 px`），最多 `center_max_iter`（默认 `5`）轮。
   - 居中后在环心周围截取固定正方形 ROI（边长 `roi_mm` 默认 `8 mm`，按当前像素尺度换算），整个扫描过程 XY 固定、不再重新检测。
   - **每点自动曝光 / 手动曝光**：居中完成后、粗找开始前，通过主相机曝光接口在该点 ROI 上确定曝光并锁定整个测点（不同测点可采用不同曝光）：
     - **自动模式（`exposure_mode: auto`）**：目标 ROI 第 99 百分位灰度 `exposure_target_p99`（默认 `190`，容差 `±15`），ROI 饱和像素（`≥ 250`）比例 `≤ 0.1%`；按线性比例最多调整 `exposure_max_iter`（默认 `5`）次，夹在 `[exposure_min_us, exposure_max_us]`（默认 `[100, 200000] µs`）。若到达上下限或最大迭代仍未完全达标，采用最接近值继续并记录警告（不回 `999`）。
     - **手动模式（`exposure_mode: manual`）**：直接应用界面/配置设置的 `manual_exposure_us` 并采图核验 ROI 灰度。运行中在界面修改曝光模式或手动值，将在**下一个测点**生效（当前测点保持已锁定曝光不变）；空闲时设置会持久化到 `runs/state/depthcal_exposure.json`。
3. **第 2 步：粗找（大步找两侧明显模糊，`coarse_up` + `coarse`）**：
   - 从居中后的 Z 开始，先以 `coarse_step_mm`（默认 `0.5 mm`）**向上大步**找“上侧明显模糊”或到达行程上限 `z_max`（若配置 `coarse_max_span_mm` 则受其限制）；随后先做顶部过冲 `overshoot_mm`，再**整段向下大步扫**（只记录向下趟采样，与细扫保持一致的回差处理），直到“下侧明显模糊”或到达安全下限 `camera_z_min_mm` / 行程下限 `z_min`。
   - **明显模糊判据**（同时兼容存在较大底值的清晰度曲线）：令 `v_peak` 为已测最大清晰度、`v_low` 为已测最小清晰度。首先须满足 `v_peak / v_low ≥ min_peak_contrast`（默认 `1.15`）才认为找到了明显清晰峰，否则报错 `DEPTH-CONTRAST`（`"清晰度变化太小，景深过大或画面太暗/对比度不足"`）。在已离开峰且呈单调下降趋势的一侧，若**连续 2 个点**满足 `(v − v_low) / (v_peak − v_low) ≤ blur_contrast_ratio`（默认 `0.3`）**或** `v / v_peak ≤ defocus_ratio`（默认 `0.3`），即判定该侧达到明显模糊。
   - 若到达上/下边界仍未达到明显模糊，记录 `"上/下侧未达明显模糊（受行程/Z 下限限制）"`，若峰在扫描内部仍继续；若最大值出现在边界点或不足 3 步，报错 `DEPTH-PEAK-BOUNDARY`。
4. **第 3 步：细扫（`fine`，重复 `repeats_per_point` 次，默认 3 次）**：
   - 默认 `fine_range_mode: auto` 时，直接以上下两侧“明显模糊”点（边界受限时用已测边界）构成细扫区间 `[blur_low_z, blur_high_z]` 均匀插点：
     - `细扫步距 = clamp((blur_high_z − blur_low_z) / fine_steps_target, fine_step_min_mm, fine_step_max_mm)`（默认目标 `40` 步，步距限制在 `[0.02, 0.25] mm`），不再使用“粗扫拟合失败回退固定 ±0.6/0.02”的逻辑。
   - 若显式配置为 `fine_range_mode: fixed`，则使用 `fine_range_mm`（默认 `0.6`）和 `fine_step_mm`（默认 `0.02`）。
   - 每次先上到 `min(blur_high_z + overshoot_mm, travel_z_max)`，再**单向向下**扫到 `max(blur_low_z, camera_z_min_mm)`。抬升阶段不采图，**只使用向下那一趟的数据**（消除丝杠反向间隙），且实测 Z 必须严格递减。
5. **第 4 步：峰位拟合、景深计算、质量门与峰位全幅留档**：
   - 对每条细扫曲线取 `≥ 50%` 最大值的点，对 `log(清晰度)` 做二次多项式高斯拟合，输出 `Z_peak`、`FWHM`（50% 半高宽）、`R²`；同时计算半高宽中点法峰位作对照。
   - **景深（DOF）定义与计算**：
     - **定义**：清晰度曲线上 `清晰度 ≥ dof_ratio × 峰值` 的 Z 区间宽度（mm）。`dof_ratio` 默认 `0.8`（即“清晰度不低于峰值 80% 的 Z 范围”），同时保留 `FWHM`（50%）作对照。
     - **原始插值法**：用每次细扫（只用向下那一趟）的原始数据，在峰两侧分别找跨过 `dof_ratio × 峰值` 阈值的相邻两点，线性插值得交点 `Z_上`、`Z_下`，`DOF = Z_上 − Z_下`。
     - **高斯解析对照**：利用高斯拟合二次项参数（`σ = sqrt(-1/(2a))`）解析计算 `DOF_gauss = σ · 2 · sqrt(2 · ln(1 / dof_ratio))` 作为对照。
     - **未覆盖判定**：若峰任一侧扫描数据未能下降跨过 `dof_ratio × 峰值`（扫描未覆盖到），该次 `DOF` 记为 **“未覆盖”**（`dof_covered = false`、`dof_mm = null`），不参与测点与全盘统计，并在界面与记录中注明。
     - **多级汇总**：**粗扫**按同法计算粗略 DOF（界面标“**粗扫估计**”）；**每个测点**汇总各次有效细扫 DOF 的均值与极差；**全盘**汇总所有有效测点 DOF 的均值、最小值与最大值。
    - **拟合质量门**：参与拟合的点在峰两侧各须 `≥ 5` 个，且最低参与点须 `≤ 0.6 × 峰值`（确认覆盖到曲线下降段）；否则该次细扫标记为 **“拟合点不足”**，在可行性结论中单列且不计入“满足”。
    - **单点多次重复容忍**：单点 `repeats_per_point`（默认 `3`）次细扫中，若仅 `1` 次拟合失败、其余 `≥ 2` 次成功且峰位极差 `≤ repeat_range_tol_mm`（默认 `0.02 mm`），该点仍记为有效并记录失败那次；若 `≥ 2` 次失败或其余极差超限，则判为该点失败。
    - 该点细扫完成后，将相机移到均值 `Z_peak` 拍一张全幅参考图留档。
6. **第 5 步：测点失败跳过/补测规则与平面判定（`161` / `999`）**：
   - **单点业务失败**：包括 `DEPTH-CONTRAST`、`DEPTH-PEAK-BOUNDARY`、`DEPTH-FIT`、`DEPTH-TARGET`（已建立参考坐标后）、`DEPTH-CENTER`、`DEPTH-ROI`、`DEPTH-DARK`、`DEPTH-FINE-RANGE`。发生时记录原因并保留该点已采曲线（界面标红），随后在菲林布局中选择**离失败点最近、未测过/未计划且在 `depth_calibration.travel` 内**的备用靶点进行补测（补测点同样按每点自动/手动曝光执行）；若补测点也失败或无可用备用点，则跳过该处继续下一个计划点。
   - **立即回 `999` 的系统/安全失败**：PLC/相机通信失败、行程/Z 下限（`POSITION-TRAVEL` / `DEPTH-Z-LIMIT`）、曝光外部改动/恢复失败、用户放弃（`DEPTH-ABORTED`）仍立即中止并回 `999`（并在恢复主相机曝光后再应答）。
   - **致命条件（回 `999`，诊断写明对应规则，恢复主相机曝光后应答）**：
     - **规则 a（`DEPTH-FIRST-TWO-FAILED`）**：最先两个计划点（含其补测）都失败，疑似设置异常提前终止；
     - **规则 b（`DEPTH-INSUFFICIENT-POINTS`）**：最终有效测点数 `< min_valid_points`（默认 `4`）；
     - **规则 c（`DEPTH-CORNER-COVERAGE`）**：任一角点及其补测点都失败（该角只能外推）；
     - **规则 d（`DEPTH-PLANE-RESIDUAL`）**：有效点拟合平面 `z = ax + by + c` 最大 `|残差| > plane_tol_mm`（默认 `0.02 mm`），自动加测四条边中点靶点（最多至 `max_points`，默认 `9`）后残差仍 `> plane_tol_mm` 且已无可加测点。
   - **非致命完成（回 `161`）**：若所有角点有覆盖、有效点 `≥ min_valid_points` 且最终平面残差 `≤ plane_tol_mm`，照常回 **`161`**；`fits.json`、`session_record.json` 与界面中均写明跳过了哪些点、原因及由哪个点补测。

- 会话中点击界面 **【放弃本次标定】**，下一个 PLC 请求回 `999` 并结束会话。
- 会话中收到非 `160` 功能码，或在其他业务模式中收到 `160`，均回 `999`。

| `exposure_mode` | `auto` | 测点曝光模式：`auto`（每点 ROI 自动曝光）或 `manual`（使用手动曝光值） |

| `exposure_max_iter` | `5` | 每点自动曝光最大线性调节次数 |
| `exposure_min_us` / `exposure_max_us` | `100` / `200000` | 自动/手动曝光允许上下限（µs） |
| `overshoot_mm` | `0.3` | 细扫顶部换向过冲余量（mm），用于避开反向间隙 |
| `repeats_per_point` | `3` | 每个靶点的细扫重复次数 |
| `frames_per_step` | `3` | 每个 Z 台阶采图帧数（取各清晰度指标中位数） |
| `metric` | `tenengrad` | 主清晰度指标：`tenengrad` / `laplacian` / `brenner`（均做均值平方亮度归一） |
| `peak_method` | `gauss` | 主拟合方法：`gauss`（对数二次拟合）/ `half_height`（半高宽中点法） |
| `dof_ratio` | `0.8` | 景深 DOF 清晰度阈值比例（清晰度 `≥ dof_ratio × 峰值` 的 Z 区间，范围 `(0, 1)`） |

| `repeat_range_tol_mm` | `0.02` | 可行性判定的重复性门限（mm），与最大极差及最大标准差比较 |
| `max_points` | `9` | 触发加测后的最大总测点数（5 至 9） |
| `min_valid_points` | `4` | 允许通过的最小最终有效测点数（3 至 `max_points`），不足触发规则 b 回 `999` |

| `position_tolerance_mm` | `0.01` | 相机步进到位均值核对容差（mm），与窗口极差共同判定到位 |
| `arrival_timeout_s` | `2.0` | 到位等待超时（秒）；超时后取最后一个窗口均值照常继续并记录异常，不回 `999` |

## 4. 如何判读界面曲线、结果表与可行性结论

界面切至 **【下针深度标定】** 页后，采用紧凑布局（1920×1080 全屏下右侧主区域展示 `≥ 480×480 px` 正方形 ROI 实时图，下方独立展示平面拟合结果，不占用 ROI 图像高度；点击 ROI 图或【放大查看】可打开实时刷新的放大窗口，并支持在**最新 ROI** 与**最近整幅居中图**间切换），重点查看以下区域：

1. **阶段栏、曝光区与“景深”实时显示**：
   - 顶部阶段栏与指标/细扫信息压缩合并，运行中实时显示当前累计到位异常次数与最新一次的 **景深 DOF（及 FWHM）**：细扫中/完成后显示最新一次细扫（如 `细扫1`/`细扫3`），仅有粗扫结果时标 `粗扫估计`；若任一侧未跨过阈值则显示 `未覆盖`。
   - 曝光区支持【自动】/【手动】切换与手动曝光（µs）设置，并实时显示当前锁定曝光与 ROI 灰度均值 / p99。
2. **清晰度曲线图**：
   - 横轴为实测 `PLC Z (mm)`，纵轴为亮度归一化清晰度；每个靶点独立一张子图。失败点保留已测曲线并标红框，补测点标题标注 `Txx(补测 Tyy)`。
   - **灰线（带圆点）** 为粗扫曲线，应呈单峰钟形；**蓝/绿/橙实线** 分别为第 1/2/3 次细扫曲线，**红色/彩色竖线** 标出拟合峰位 `Z_peak`。
   - **浅蓝色水平虚线** 标出 `dof_ratio × 峰值` 阈值，**浅蓝阴影区域及两端短竖线** 标出交点 `Z_下` 与 `Z_上` 之间的景深区间。
   - 理想情况：3 条细扫曲线几乎重合、峰部光滑对称、竖线基本重叠在一条线上。
3. **各测点结果表与到位 / 跳过补测汇总**：
   - 表上方并排显示全程到位汇总与**跳过/补测汇总**（写明跳过了哪些点、原因及由哪个点补测）。到位正常时显示 `到位：全部在 ±0.01 mm 内（平均等待 x.xx s）`；存在超差/未稳定时显示 `到位超差点：T02、T26（共 N 次，最大 Z +0.023 mm，详见 arrivals.csv）`。
   - 查看每点 `细扫1/2/3 Z`（单次拟合失败会注明 `失败`）、`极差`、`标准差`、`FWHM`、`DOF 均值`、`DOF 极差`、`R²`（高斯拟合优度，越接近 1 越理想）及 **`到位超差`**（无异常显示 `—`，有则显示如 `3/126 次 · 最大 Z +0.023` 且该行标黄）。失败点行整行标红，补测点标注 `Txx(补测 Tyy)`。到位异常仅做记录与提示，不影响可行性结论判定。
   - 若某测点部分细扫未覆盖，将在 `DOF 均值` 中注明未覆盖次数（不参与均值与极差统计）；全部未覆盖则记 `未覆盖`。
   - 若某点 `R²` 明显偏低或 `FWHM`/`DOF` 过大，需检查该点照明反光或扫描范围是否只覆盖了单侧。
4. **平面拟合结果与加测说明**：
   - 查看平面方程 `z = ax + by + c`、最大 `|残差|` 与倾斜量（`mm/100mm`）。
   - 若最大 `|残差| > 0.02 mm` 触发加测至 9 点，对照 **"加测后残差下降 / 不变 / 增大"**：
     - **加测后残差仍与初测相当或呈系统曲面**：多为料盘本身存在局部起伏/弯曲；
     - **某单点残差突兀且其它点很平**：多为该点测量误差、菲林翘起或异常污渍。
5. **可行性结论栏与全盘景深汇总**：
   - **可行性结论**：汇总全部测点细扫 `Z_peak` 的 **最大极差** 与 **最大标准差**，与 `repeat_range_tol_mm`（默认 `0.02 mm`）比较。若存在任意一次细扫未通过质量门（峰两侧拟合点不足 5 个或最低参与点 `> 0.6 × 峰值`），可行性结论中将单列 **“拟合点不足 x/y 次（不计入满足）”**，整体判定为不满足。满足门限且无拟合点不足时显示绿色：**"对焦重复性满足下针深度标定误差预算（总 0.05mm，对焦环节约 0.02mm）"**。
   - **全盘景深汇总**：显示 `dof_ratio` 及所有有效测点景深的 **均值 / 最小 / 最大（mm）**；若有未覆盖细扫，会额外注明未覆盖次数且不计入统计。

## 4.5 每测点往返次数与总时长估算（按每步 1.5 s）

在 `fine_range_mode: auto` 默认参数下（`coarse_range_mm=3.0`、`coarse_step_mm=0.2`、`defocus_ratio=0.3`、`repeats_per_point=3`、`fine_steps_target=40`）：

- **居中**：每点通常 `1–3` 轮（按典型 `2` 次往返计）。
- **粗扫**：最大 `31` 步；因 `defocus_ratio=0.3` 提前离焦停止，在预计 `FWHM = 1–3 mm` 时通常需 `20–28` 次往返。
- **细扫（3 次）**：
  - `FWHM = 0.5 mm` → 半宽 `0.375 mm`、步距 `0.020 mm`：`39` 采样 + `1` 抬升 = `40 × 3 = 120` 次往返；
  - `FWHM = 1.0–2.67 mm`（典型 `2.0 mm` 半宽 `1.50 mm`、步距 `0.075 mm`）→ `41` 采样 + `1` 抬升 = `42 × 3 = 126` 次往返；
  - `FWHM = 3.0 mm` → 半宽 `2.250 mm`、步距 `0.100 mm`（触及步距上限）：`46` 采样 + `1` 抬升 = `47 × 3 = 141` 次往返；
  - `FWHM = 4.0 mm` → 半宽 `3.000 mm`（触及半宽上限）、步距 `0.100 mm`：`61` 采样 + `1` 抬升 = `62 × 3 = 186` 次往返。
- **峰位全幅留档**：每点 `1` 次往返。

因此，针对现场主相机预计 `FWHM = 1–3 mm` 的典型工况：
- **单点预计往返次数**：`~149–172 次`（典型约 `155 次`）；
- **单点预计时长**（按 `1.5 s / 步`）：`~224–258 s`（约 `3.7–4.3 分钟/点`）；
- **5 点总计**：`~745–860 次` 往返，约 **`19–21.5 分钟`**；
- **若触发加测至 9 点**：`~1340–1548 次` 往返，约 **`33.5–38.7 分钟`**。

## 5. 记录文件位置与内容

每次会话自动保存到 `runs/<日期>/depthcal/<会话>/`：
- `curves.csv`：每步原始记录（`label, pass, direction, z_cmd, z_actual, tenengrad, laplacian, brenner, exposure_us, roi_mean, roi_p99`）。
- `arrivals.csv`：每次 160 到位采样记录（`label, phase, seq, expected_x, expected_y, expected_z, actual_x, actual_y, actual_z, delta_x, delta_y, delta_z, max_abs_delta_mm, max_delta_axis, ptp_x, ptp_y, ptp_z, status, elapsed_s, samples`），其中 `status` 为 `ok` / `超差` / `未稳定` / `超差+未稳定`。
- `roi/*.png`：每步所选中位帧的 ROI 裁剪图。
- `<标签>_center.png` / `<标签>_peak.png`：每个靶点居中后与均值峰位处的全幅原图。
- `fits.json`：每个测点的 3 种清晰度拟合结果（含高斯与半高宽对照、每次细扫的 `dof_mm`、`dof_gauss_mm`、`dof_ratio`、交点 `dof_z_lower`/`dof_z_upper`、`dof_covered`、测点 `dof_mm`/`dof_range_mm`、测点 `arrival` 统计、补测来源 `retest_of` 与单次失败 `failed_repeats`）、失败跳过/补测记录 `failed_points` 与 `skip_summary`、可行性汇总、全盘 `dof_summary` 与顶层 `arrival_summary`。
- `plane.json`：初测 5 点与加测后平面方程、各点残差、倾斜量及残差变化判定。
- `plc.jsonl`、`events.jsonl` & `session_record.json`：全部 PLC 请求/应答序列、配置快照、固定曝光值与恢复状态、失败跳过/补测详情 `failed_points`/`skip_summary`、到位异常警告事件 `depthcal_arrival_warning`、全盘景深汇总 `dof_summary`、到位汇总 `arrival_summary` 与结束诊断。

## 6. 常见失败原因与错误码对照

| 错误码 | 现象 | 位置 | 现场排查建议 |
|---|---|---|---|
| `DEPTH-Z-MIN` | 未配置相机 Z 下限 | `160` 会话启动 | 核查两把工具与料盘间隙后在 `config/nest_clear.yaml` 填写 `depth_calibration.camera_z_min_mm` |
| `DEPTH-Z-LIMIT` | 目标或实测 Z 低于安全下限 | 下发/到位安全守卫 | 提高初始 Z，或重新评估工具间隙与 `camera_z_min_mm` |
| `DEPTH-UNIMPLEMENTED` | 收到 `170/171/180/181/190/191` | PLC 请求 | 本阶段只使用 `160`，勿发后续阶段功能码 |
| `DEPTH-MODE` | 当前模式不允许或会话中收到非 `160` | PLC 请求 | 空闲态从 `160` 发起；会话中只连续发 `160` |
| `DEPTH-CALIBRATION` | 缺少有效主相机标定 | `160` 会话启动 | 先通过 `80` 完成主相机标定（非占位文件） |
| `DEPTH-EXPOSURE` | 未关闭自动曝光或扫描中曝光改变 | 采图前置/采图校验 | 检查主相机曝光设置；确认无外部程序中途改动当前点锁定曝光 |
| `DEPTH-CONTRAST` | 清晰度变化太小（`v_peak / v_low < min_peak_contrast`） | 粗找判定 | 检查照明、曝光、焦距，确认画面有足够对比度且覆盖清晰峰 |
| `DEPTH-TARGET` | 未识别到菲林靶点或靶点标签跳变 | 居中识别 | 检查初始位置是否正对菲林、菲林旋转方向、光照与初始焦距 |
| `DEPTH-CENTER` | 达到居中上限仍未进入 `center_tol_px` | 居中循环 | 检查主相机标定投影精度、PLC XY 到位精度与 `center_tol_px` |
| `DEPTH-ROI` | 固定 ROI 超出图像边界 | 居中结束取 ROI | 减小 `roi_mm` 或检查像素比例尺与居中性 |
| `DEPTH-PEAK-BOUNDARY` | 对焦峰出现在粗扫/细扫边界或不足 3 步 | 粗扫 / 细扫 | 根据提示方向（`Z+` 向上或 `Z−` 向下）调整初始 `Z0` 或扫描范围 |
| `DEPTH-DIRECTION` | 细扫/粗扫实测 Z 未严格下降 | 扫描步进 | 检查 `fine_step_mm`、PLC Z 到位精度与 `position_tolerance_mm` |
| `DEPTH-FINE-RANGE` | Z 行程不足以完成换向过冲与细扫 | 细扫规划 | 调整初始 Z、缩小 `fine_range_mm` / `overshoot_mm` 或确认 Z 行程 |
| `DEPTH-FIT` | 高斯或半高宽峰拟合失败 | 细扫拟合 | 检查细扫范围是否覆盖半高宽两侧，尝试更换 `metric` 或曝光 |
| `DEPTH-PLANE` | 测点共线无法拟合平面 | 平面判定 | 确保 `point_order` 包含二维分散靶点 |
| `DEPTH-FIRST-TWO-FAILED` | 最先两个计划点都失败（规则 a） | 跳过/补测规则 | 检查初始 `Z0`、曝光、照明与菲林位置后重试 |
| `DEPTH-INSUFFICIENT-POINTS` | 最终有效点数不足 `min_valid_points`（规则 b） | 跳过/补测规则 | 检查失败测点原因并确认参数与光照 |
| `DEPTH-CORNER-COVERAGE` | 任一角点及其补测点都失败（规则 c） | 跳过/补测规则 | 检查缺失角点区域光照、菲林固定或行程范围 |
| `DEPTH-PLANE-RESIDUAL` | 平面最大残差超差且无可加测点（规则 d） | 平面判定 | 检查料盘平整度、菲林贴合度与异常测点曲线 |
| `DEPTH-ABORTED` | 操作员在界面点击【放弃本次标定】 | 会话控制 | 确认放弃后可重新发 `160` 开始新测试 |
