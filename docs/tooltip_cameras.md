# 对刀相机接线和测量

正面为主相机，侧面为辅助相机。目前两台都已识别，均在 Intel 00:14.0 控制器上：

- `/dev/v4l/by-path/pci-0000:00:14.0-usb-0:4:1.0-video-index0`
- `/dev/v4l/by-path/pci-0000:00:14.0-usb-0:8:1.0-video-index0`

哪台是正面或侧面尚未确认，配置暂均为占位。两台直连 xHCI 不同根端口，各自独享 480M；经过 hub 时才共享链路。带宽不足时界面会提示，再换口。换口后 by-path 会变化，须重新确认视图和路径。使用 `video-index0`，不要使用同一相机的元数据节点。镜头手动调焦，背光亮度固定。

`tool_calibration.camera_controls` 是共享设置，`cameras.front/side.camera_controls` 可以覆盖。YUYV 和宽高由采集器设置并回读；手动曝光、动态帧率、自动白平衡、色温、增益、锐化、背光补偿、伽马、亮度、对比度、饱和度、色调和电源频率通过 V4L2 控制。关闭锐化避免人为改变边缘，关闭背光补偿避免改变剪影灰度，关闭动态帧率保证采样稳定，关闭自动白平衡避免画面变化。亮度、对比度、饱和度、色调默认采用设备报告的默认值，其他默认值见配置接口。

打开流后设置控制项，丢弃三帧再逐项回读；不匹配则报错。手动测光以中央 80% 区域的 P99 达到 200–235 且 250 以上像素少于 0.1% 为目标，检测到暗剪影时排除其区域。从当前配置或已保存的曝光开始，按倍数扩展至夹住目标，再对数二分，并等待画面稳定。默认上限 1600（160ms）约等于 6fps 帧周期，再长会降帧；设备上限为 5000，背光足够时不应需要更长曝光；过暗检查照明、镜头和遮挡，过曝检查光路；不收敛时检查闪烁和场景。保存测量后重开时使用已测曝光，不自动重新测量。设备或光路改变后应重新测量。

`config/calibration/tooltip_cameras.yaml` 的 `cameras` 按 front/side 保存 `measured`、`device`、`exposure`（100µs）、`controls` 实际回读、`width`、`height`、`format`、`time`、`p99`、`saturated_fraction` 和 `contrast`。未测模板的 `measured` 为 false。每次写入前备份至同目录 `history/`。

`devices.front` 和 `devices.side` 保存主、辅相机的 by-path 分配；为空时回退到主配置。分配是现场数据，模板保持空值。曝光按设备路径匹配，主辅对调后仍使用该设备的已测曝光。

程序同时按设备路径保留测量记录，主辅对调或分别重新测量后，各设备仍使用自己的已测曝光。未测设备首次打开预览时自动测光，失败会保留原曝光并提示，可在界面重测。

预览中可先用“设置曝光”临时调节，再点击“设为实际曝光”并确认，将硬件当前回读值按设备路径保存；“恢复曝光”恢复该设备已存值（无记录时恢复默认值）。记录包含时间和画面 P99、饱和比例，画面测量失败时指标为空但曝光仍保存。`source=manual` 表示手动保存，`source=auto` 表示自动测量；旧记录没有 `source` 时按自动测量显示。重开预览使用已存值，不自动重测。
