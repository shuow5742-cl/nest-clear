# 换针对刀现场操作

1. 确认主、辅助相机和背光正常，PLC 把选定工具移至该工具的 P0 后发 100/101。界面自动显示工具号。观察两视图基准点、范围圈和针尖；检查横竖偏差、当前修正量及目标坐标。
2. 雅可比未测时先进入探测：依次检查并确认 X、Y、Z 的 +0.2 mm 探测目标及回 P0，共四次。每次按【确认移动】后等待 PLC 到位和新图。探测不占正常对准次数。质量合格后自动备份基准并保存测得的雅可比。
3. 对准阶段每次检查针尖位置、Δxyz、目标和相对 P0 的移动量，确认安全后按【确认移动】。识别位置不准时按【识别不准，手动点击】，依次在放大图中选择主、辅相机针尖；检查重算结果后再确认。红字提示修正量过大时无法下发，可重新点选或放弃。
4. 显示“已在范围内”时检查两视图和数据，按【确认对刀结果】；等待 PLC 130。界面显示旧补偿、新补偿及差值，保存前无需再次确认。按【放弃对刀】返回 131。
5. 到位超差时检查 PLC 实际坐标与目标；无法识别或探测质量不合格时检查针尖是否在视野、对焦、背光和相机固定情况，重新建立基准或重新执行对刀。最终坐标不一致时检查 PLC 最后到位值及寄存器。原图、事件和 `tooltip/<首个任务号>/session_record.json` 位于运行目录。

默认单步任一轴上限 0.5 mm、相对 P0 任一轴上限 2.0 mm；探测步长 0.2 mm，均在 `tool_calibration` 下配置。默认像素比例为估算值，现场必须实测 `config/tooltip_baseline.yaml`。界面等待人工确认时请求不会自动应答，超时由 PLC 处理。
