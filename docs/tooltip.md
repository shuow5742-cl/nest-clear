# 双相机针尖对准

本模块只负责针尖检测、局部线性求解和基准 YAML；采图、运动、行程守卫、会话状态、PLC 通信及运行补偿保存由后续流程负责。模型假设相机固定、模组位移较小，雅可比只在基准 P0 附近有效。正面相机主要观察 X/Z，侧面相机主要观察 Y/Z；像素坐标为 (u, v)，模组坐标为 (x, y, z)，单位 mm。

每个视图的目标像素为 t，2×3 雅可比 J 的单位为像素/mm。已知模组位移 d 引起的像素位移近似为 Jd。`fit_view_jacobian` 用同一参考点的位移样本最小二乘拟合 J；样本须覆盖三个独立方向。`solve_correction` 将所有视图堆叠，求解 `JΔ = t − observed`，要求视图齐全、堆叠矩阵满列秩。可指定正权重；`primary_view` 的权重额外乘二，这只是偏向主视图，并非强制 Z 完全取正面结果。§9 要求 Z 以正面为准，后续协议流程须明确实现这一策略，不能仅依赖该参数。

结果包含下一步模组修正量 Δ、各视图像素残差和伪逆投影到模组空间的残差；后者是最小范数投影，并非完整三维误差。条件数反映联合矩阵的病态程度。`axis_estimates` 固定其他轴为联合解后估计各轴，`axis_disagreement` 是各视图估计之差，受轴间耦合影响；后续流程应检查两相机 Z 分歧并按 §9 记录警告。

每轮采集两台相机并检测针尖，求解后用 `check_quality` 独立检查投影残差和条件数，调用方依据诊断决定告警或停止。质量检查不等于收敛判断：即使两视图互相矛盾，联合修正也可能接近零。`is_aligned` 判断各轴修正绝对值是否均不超过容差；未到位时，行程检查通过后移动至当前坐标 + Δ，再采图迭代。到位、检测失败、运动或位置校验失败、超过最大偏移次数等均为终止条件；失败时协议流程回 131。剪影检测器采用暗像素阈值、最大连通域和指定方向极值，受背景及遮挡影响，其置信度不是概率。

对应 [design.md §9](design.md)：100/101 时验证实际位置与 P0，之后采图求解并按首次或后续偏移回复对应功能码；110/120 到位后校验并继续迭代，到位回复 111/121。130 时校验最终坐标，再计算 `Δ = P_final − P0`。按 §8，`pick = target + compensation`，所以新补偿 = 基准补偿 + Δ；`compute_compensation` 默认采用此约定，保留反号选项以兼容原接口。最终补偿文件的原子写入、备份、历史和即时生效属于后续协议流程；`save_baseline` 只写版本 1 的基准 YAML，不提供这些功能。
