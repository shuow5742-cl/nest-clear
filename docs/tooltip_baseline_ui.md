# 对刀基准建立现场操作

1. 确认主程序运行、PLC 已初始化且空闲，将 PLC 置于手动模式。确认两台板卡相机固定、背光和焦距正常。
2. 在“对刀基准建立”页按【开始对刀基准建立】，选工具1或工具2。核对工具色块、当前补偿和已有基准；工具偏移缺失或较新时会提示，但不阻止操作。
3. 点动工具，使针尖进入主对刀相机画面中心圆。横向、竖向读数为像素换算的画面偏差，绿色表示进入圆内。两相机比例默认 15.2 μm/px 是 8 mm 镜头估算值，现场须实测后更新 `config/tooltip_baseline.yaml` 的 `baseline_ui`；主相机默认半径 0.05 mm。
4. 按【对刀基准】并保持位置稳定。检查主/辅像素、偏差、清晰度和 P0。若失败，按提示调整后重试。识别位置不准时可按【识别不准，手动确认】在放大窗口分别选取两视图针尖；仅辅助位置不准时可【辅助相机手动重设】。
5. 成功后按【保存基准】，检查新旧时间、P0 和两视图针尖以及差值，选择【覆盖保存】。选择【不保存】回到可重试状态。
6. 保存成功后，请电气人员在 PLC 侧记录当前坐标为对应工具对刀基准位置。按【结束/放弃】关闭两台板卡相机。PLC 在会话中发出的功能码均回 999，须先在界面结束。

本次建立的基准不含雅可比，换针对刀方案尚待确定，100/101 将回 131。保存路径由运行配置的 `tool_calibration.directory` 指定：生产为 `config/calibration/`，通信联调为 `config/commtest_calibration/`；旧文件备份到同目录 `history/`。原图、事件与 `session_record.json` 在本次运行的 `baseline/` 目录中。算法不向 PLC 写基准或运动地址。
