# 对刀基准建立现场操作

1. 确认主程序运行、PLC 已初始化且空闲，将 PLC 置于手动模式。在“对刀基准建立”页分别选择主对刀相机（正面）和辅助对刀相机（侧面）；必要时使用【主辅对调】确认对应关系。
2. 打开两路预览，手动点动针尖至主相机中心容许圆。PLC 在准备及基准会话期间的请求回 999，须先在界面结束。
3. 手动调整两台镜头位置和焦距，观察各自清晰度百分比、边缘宽度和曲线，在清晰度最高处固定镜头。针尖未识别时按画面中央计算；针尖移动超过 50 像素或点击【峰值清零】可重新跟踪峰值。
4. 未测设备打开时自动测曝光；画面变化后可点击【重新测曝光】。背光亮度固定，不调光源。
5. 点击【开始对刀基准建立】，选择工具，按【对刀基准】并保持位置稳定。检查主/辅像素、偏差、清晰度和 P0；识别不准时可手动确认。
6. 按【保存基准】并确认覆盖；请电气人员在 PLC 侧记录当前坐标。按【结束/放弃】结束会话。相机设置变化时须重建基准。

本次建立的基准不含雅可比；换针对刀时按现有流程完成后续测量。保存路径由运行配置的 `tool_calibration.directory` 指定：使用 `config/calibration/`；旧文件备份到同目录 `history/`。原图、事件与 `session_record.json` 在本次运行的 `baseline/` 目录中。算法不向 PLC 写基准或运动地址。
