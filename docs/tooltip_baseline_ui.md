# 对刀基准建立现场操作

1. 确认主程序运行、PLC 已初始化且空闲，将 PLC 置于手动模式。在“对刀基准建立”页确认主对刀相机（正面）和辅助对刀相机（侧面）已按插口固定对应。
2. 打开两路预览，或点击【开始对刀基准建立】并选择工具。PLC 在准备及基准会话期间的请求回 999，须先在界面结束。
3. **两路清晰度对准规则（取消主相机视野中心约束）**：
   - 正面相机沿 Y 方向看 → **点动 Y** 找正面最清晰；
   - 侧面相机沿 X 方向看 → **点动 X** 找侧面最清晰；
   - Z 两路都在画面竖直方向，不影响清晰度，只需使针尖在两路画面内且离画面边缘 ≥ `edge_margin_px`（默认 40 px，太靠边时按界面提示点动 Z/X/Y 移回画面中部）。
   - 主相机中心偏差仅作灰色参考显示，不再要求针尖进入中心容许圆。
4. 人工点动工具寻找两路清晰度峰值（每路清晰度取最近 `focus_smooth_frames` 默认 5 帧的中值抗抖动，峰值也基于平滑值；需累计至少 `peak_min_frames` 默认 10 帧有效样本）。**越峰确认**：峰值出现后，须先继续点动越过最清晰点使清晰度降到 ≤ `focus_pass_percent`（默认 92）% 峰值以确认峰值，再往回点动到 ≥ `focus_ready_percent`（默认 95）%；若出现新的更高平滑峰值，越峰确认会重置并需重新越峰。界面每路显示阶段：“继续同方向点动（尚未越过最清晰点）”→“已越峰，往回点动到峰值附近”→“✔ 最清晰”。换工具或重新开始时点击【清晰度峰值清零】将两路同时清零。
5. 未测设备打开时自动测曝光；画面变化后可点击【重新测曝光】。背光亮度固定，不调光源。
6. 当两路均满足“精定位（或已人工点选）、已完成越峰确认、清晰度 ≥ 95%、边缘宽度 ≤ `focus_max_px`（默认 3.0 px，兜底上限；`focus_good_px` 2.0 / `focus_warn_px` 3.0 仅决定绿/黄/红颜色，如 2.4 px 黄色且相对峰值满足仍可就绪并提示‘该路最佳边缘 2.4px 偏宽，可接受’）、连续 5 帧达标且不靠边”时，顶部显示绿色“✔ 两路针尖都最清晰，可作为对刀基准 → 点【对刀基准】”，此时可按【对刀基准】并保持位置稳定；任一路未就绪时按钮置灰并显示需调整的相机与轴。若某路识别不准，可点击该路【人工点选】按“已人工确认”参与就绪判定（清晰度与越峰条件仍须满足），或使用【识别不准，手动确认】/【辅助相机手动重设】。
7. 按【保存基准】并确认覆盖；请电气人员在 PLC 侧记录当前坐标。按【结束/放弃】结束会话。相机设置变化时须重建基准。

本次建立的基准不含雅可比，记录两路像素位置、P0、两路清晰度百分比/边缘宽度/峰值/越峰确认状态、判定参数与规则版本 `focus_both_v1`；换针对刀（100/110 + 40905=2）时比较两路观察像素与基准保存的目标像素，首次自动探测并保存雅可比。保存路径由运行配置的 `tool_calibration.directory` 指定：使用 `config/calibration/`；旧文件备份到同目录 `history/`。原图、事件、`focus_trace.csv`（两路原始/平滑清晰度、峰值、百分比、边缘宽、对比度、轴残差、检测状态、越峰阶段与就绪状态）与 `session_record.json` 在本次运行的 `baseline/` 目录中。算法不向 PLC 写基准或运动地址。
