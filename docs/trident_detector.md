# 三棱针检测实验

`TridentTipDetector(TridentConfig(x_range=None, min_height=100)).detect(gray)` 接受二维 uint8 灰度图，输出坐标、轴、末端候选、状态、中文诊断、二值工具掩膜、清晰度指标、耗时和采样行。坐标为图像 (u,v)，轴指向画面下方。`x_range` 为可选左闭右开横坐标范围。

先将图像缩小四倍，以 110 灰度选取接触顶部但不接触底部和左右边缘的细长连通域；候选不唯一时拒绝。候选局部区域使用 61×31 膨胀估计背景，以背景的 78% 建立暗区并寻找顶部连通域。该方法对灰齿有一定适应性，但不能保证断开的齿被识别。末端前 80 像素以外、距末端不超过 300 像素且不早于末端高度 40% 的区间作为针身段；每三行用局部针体及背景平台的 50% 穿越位置确定左右边缘，拟合中点并剔除异常行。末端区域沿轴向平行扫描，以局部针体和背景中间灰度插值，要求连续五点暗度支持，并限制在连通域末端之后 5 像素以内以抑制背景暗物；该限制可能遗漏完全断开的更长齿。`prong_tips` 暂存扫描线末端候选，并不表示已分离出的各齿。工具尖为轴线在通过该齿尖的法线上的交点。

针身边缘使用局部平台归一化，报告 10–90% 宽度和最大梯度的中位数。该算法尚不能可靠分离相连齿，也没有可靠的针身/针尖语义分割；质量状态仅为实验性筛查，不能用于生产对刀。评测中固定末端前 75 像素的分界只用于计算近似 IoU，不是分割真值。

运行 `PYTHONPATH=src python tools/tip_eval/eval_trident.py --baseline` 和 `PYTHONPATH=src python tools/tip_eval/eval_trident.py`；后者需要 matplotlib，以及脚本所列只读数据路径。输出写到 `/home/shuow/nest-clear-field/20261125_t79eval/`。实测结果和限制见输出目录 report.md。

质量状态实验门限：单帧轴线中点残差 RMS ≤0.7 px、最远剖面对比度 ≥40 灰度、至少三条有效轴向剖面，且最远点不在搜索上限附近时标为精定位；单帧结果不证明跨帧稳定。`detect_sequence` 恰好接收五帧，u、v 各自总体标准差须 ≤0.1 px，否则将有坐标的结果降为粗定位并保留坐标及原因。质量门限尚需独立验证，精定位状态不保证达到人工标注误差验收。

清晰度 ESF 将每行左右外边缘的灰度剖面，以半高边缘对齐，分别按局部内外平台归一化后平均，输出平均曲线的 10–90% 宽度；另报告针身带水平灰度差绝对值的 99.5 分位数。五帧均值、总体标准差与逐帧值在评测 CSV 中。当前真实扫描两者均不满足目标，不能用于对焦判定；局部针体平台、窄针身和侧面双齿结构可能使剖面不满足单边缘假设。
