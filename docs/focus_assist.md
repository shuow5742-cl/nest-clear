# 对焦、光圈与曝光自测

推荐现场顺序：

1. 先修好光源，确认亮度稳定、照明均匀。主程序停止后，在相机标定页打开“对焦/光圈辅助”。
2. 光圈全开，缓慢转动对焦圈找中心清晰度峰值，回到峰值的至少 98% 处并锁紧。需要重新找峰值时点“重置峰值”。
3. 光圈收到 F2.8～F4。分别使用 0、2、4、5 mm 垫片，输入备注并点“记录当前”，比较景深；选择在 5 mm 范围内清晰度均达到峰值至少 80% 的最大光圈。保持照明、目标与相机位置一致。记录在 runs 目录的 `focus_records/日期/records.jsonl` 和相邻 JPG 缩略图中。
4. 保持镜头和光圈固定，执行“曝光自测”，选择默认的“标定用（角点最多）”。扫描结束检查表格和推荐值，确认“应用推荐曝光”。也可选“亮度目标”，在合格档中选择 P99 最接近 220 的曝光。扫描可取消；结束、取消及异常时会恢复扫描前的曝光，扫描过程中画面采集暂由自测占用。
5. 设置白平衡，然后执行相机标定 80。关闭辅助可释放相机。

曝光自测按配置范围几何等比分档，默认 500～30000 us、10 档，切换后丢弃 1 帧；可通过 `ui_preview.exposure_sweep` 的 `min_us`、`max_us`、`steps`、`settle_frames` 配置。每档在原分辨率检测 ChArUco；以角点凸包为统计区域，未检测时使用中央 80%。饱和像素使用标定配置的 `saturation_level`，彩色图像按最大通道判断。表格显示曝光、饱和比例、P99、角点数与中心清晰度。标定用模式排除饱和比例高于 `camera_calibration.max_saturated_fraction` 的档，在角点数不低于最高数 98% 的档中选择中间档。无法满足条件时显示原因；没有推荐时不能应用。

应用前需要确认旧值和新值。结果仅写入相机标定结果同目录的 `camera_exposure.yaml`，已有覆盖文件会先备份到 `history`；不会修改原配置文件。覆盖曝光在配置下次加载时生效，界面显示曝光来源和自测时间。应用不会立即改变当前预览曝光，主程序下次启动生效。扫描不会改变增益或光圈。

中心及九格中位数是原分辨率梯度能量，按亮度归一化；Laplacian 方差供参考。九格百分比是各格当前值相对于本会话各自峰值的比例，并非格与格之间的绝对清晰度比较。绿、黄、红分别表示至少 98%、90% 至 98%、低于 90%。四角提示表示角格相对自身峰值的变化与中心不同，可能与镜头、纸面平整度或场曲有关。曲线显示最近 30 秒中心读数。
