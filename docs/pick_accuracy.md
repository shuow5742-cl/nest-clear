# 挑取精度标定现场操作

完成相机标定和工具偏移标定，核对起始坐标、行程、板厚、卡厚和精定位框。将菲林片平整固定在料盘面，按实际尺寸打印；整个会话不要移动卡片。建议以相同光照、工作高度和人工对准方式操作。`pick_accuracy.calib_tool_z_mm` 默认 −10 mm，须根据现场确认；工具移动和点动由 PLC 控制。

1. PLC 空闲发送 150，在“挑取精度标定”页选择工具并按“开始”。PLC 移动到返回的相机坐标，到位后发送 155。总览与目标对中可能要求再次移动相机。
2. 界面显示“工具已到位”时，将所选工具手动对准黄色标出的圆环中心，停稳后按“计算补偿”。如果轴未停稳，等待后再按；对准失误可按“本点作废重测”。PLC 根据 156 继续请求下一点。
3. 观察料盘图、残差和视野内检查。黄色框内不均警告提示复核相机标定，不会单独导致失败。系统按测量结果选择固定补偿或位置补偿表，并使用验证点检查。
4. 覆盖确认弹窗出现后核对工具、类型、旧结果、新结果及验证结果。按“覆盖保存”才写入结果并返回 151；“不保存”或“放弃本次标定”返回 152。旧文件保存在同目录 history。联调和生产目录独立。
5. 工具 XY 偏移或相机标定改变时界面显示黄色提示，需要重新验证。生产仍使用已保存值。生产无该工具结果时补偿为零，并记录未标定警告。

未找到卡片或识别质量差：检查卡片、对焦、照明和打印比例；对中重试超限：检查相机标定和机械运动；相机到位超差/错序 999：检查 PLC 顺序和实际坐标；不可重复：检查机械间隙、卡片移动和人工对准；补偿后仍超差：检查相机标定、机械精度和卡片，再重新标定。行程不可达点会记录并跳过；测点不足时不能生成结果。
