# 毛检测：一代兼容与二代尺度

`detect_candidates(image, cfg)` 接收已经换算的配置，返回所有最终团块；`gen1_pixel_gates` 是一代兼容的长度、面积、宽度、暗度四门，后续二代物理门尚未接入。调用方对 YAML 读取的参考配置只调用一次 `scaled(cfg)`，再传给检测器；不要对已换算配置重复调用 `scaled`。`effective_pixel_values(cfg)` 返回可用于启动日志的实际像素参数及三道换算后的像素门；主程序日志接入留待后续任务。

12 步按顺序是：

1. 暗核：绝对灰度阈值与形态学清理。
2. 细线：局部对比度检测及暗核去重。
3. 纤维团：处理图上检测局部细纤维密度。
4. 桥接：结合暗度与方向连接相近暗核。
5. 线拟合：连接共线断续小暗核。
6. 合并：合并空间接近的团块。
7. 包含抑制：删除被包含的重复团块。
8. 种子生长：从暗核沿弱暗区域生长。
9. 轴追踪：沿局部暗脊延伸短碎片。
10. 再次包含抑制：去除生长后重叠。
11. 取点精修：依据证据厚度与中心性选点、拟合角度。
12. 分类与排序：计算长度、暗度并按面积排序；挑取门单独调用。

## 尺度与取整

一代参考尺度为 6.959 µm/像素，二代名义值为 27.75 µm/像素；后者是 1.85 µm 像元、120 mm 工作距离、8 mm 焦距的名义估计，现场应按实际标定更改。令 `k = reference_um_per_px / um_per_px`：长度乘 k，面积乘 k²；整数按 Python `round` 取整，长度与面积至少为 1，浮点长度至少为 1e-6（保证距离和除数有效）。奇数核取最邻近奇数，平局向大取，至少为 3：1×1 不形成有效形态学邻域。可关闭的生长半径保留 0，否则至少为 1。降采样参数单独换算：整数倍数 `ds_eff=max(1,round(ds_ref×k))`，浮点比例 `s_eff=min(1,s_ref/k)`，不会放大输入图像。纤维处理图核原本以一代处理图像素为单位，先乘一代 `fiber_ds` 换算到一代原图，再乘 k 并除以 `ds_eff`，最后按奇数核取整。纤维面积门是全分辨率面积：处理图面积乘 `ds_eff²` 后与已按 k² 换算的门比较。

背景高斯与种子生长先把标准差换算到当前原图，再乘各自处理图比例；生长闭运算半径同样先换算原图半径，再乘生长比例。合并分组先用换算后的原图间距，再除以实际分组倍数求处理图膨胀半径。`merge_close_bound_min_px` 为决定闭运算优化分支的原图像素数门槛，按 k² 换算；直接和分块分支执行相同闭运算。PCA 采样上限、桥接轮廓点上限、线拟合最大轮数是计算预算，保持不变；灰度、比例、角度、迭代次数、像素格邻接和数值稳定项也不缩放。

兼容挑取门直接按当前 µm/像素把毫米与平方毫米换成像素，使用一代的 `round`。

下表与 `scaling.INVENTORY` 同源；表中元组是采样两侧的距离。固定类的尺度参数及毫米门保留本身单位。没有可恢复的真实细节：比 1–2 像素还细的丝可能看不见；1 像素下限与插值会使二代结果不可能与一代逐像素相同。场景测试只验证已覆盖的粗目标，不能推断现场召回率。

## 一代兼容及 golden

显式构造 `HairDetectConfig(um_per_px=6.959)` 并执行 `scaled` 即为兼容模式；k=1 返回原对象，所有参考参数不变。常规 YAML 的参数是参考值，`um_per_px` 默认 27.75。OpenCV 固定 4.11.0.86：5.0 在现场图上的轮廓、面积及角度与一代不同。实心轮廓填满边界框时，一代和本实现的 float32 距离中位数可能溢出为 inf 并发出 NumPy 警告，保留此行为。

在本机一代目录运行以下命令，使用一代 venv 导出 13 个合成场景、按 run 分层固定种子选取的 60 张现场图和阶段变化统计；现场图片不入库：

```bash
cd ~/pluck-hair/backend
.venv/bin/python ~/nest-clear-t12/tools/export_gen1_hair_golden.py --mode all
```

现场数据目录缺失时真实图测试跳过。执行 `python tools/benchmark_hair.py` 可打印 4024×3036 图像五次单帧中位数与各阶段耗时；这不是性能断言，机器和图像复杂度都会影响结果。
