- 新增 PC→PLC **40932 算法启动完成**（UINT16，0/1）。

- PLC→PC 功能码 40904：1 任务请求，20 拍照到位，60 挑取结束（另有对刀 100/101/110/120/130 不变）。
- PC→PLC 功能码 40934（工作模式）：1 扫描（带坐标 40942/44/46），3 去挑取，9 本盘结束，10 工具需更换，999 错误。**PC 永不回 60**（清洗由 PLC 每挑必做）。

## B. 父程序 / 40932
- 父程序：在拉起主程序之前、杀死主程序之后、以及发现主程序意外退出时，写 40932=0。
- 主程序：启动预检通过、按现有规则写完 40933=0/40934=0 并取 40903 基线后，写 40932=1，再开始监听 40903。
- 其余父程序规则（bit7 拉起/重启、bit6、暂停、看门狗、代答 999）不变。

## C. 工作模式状态机（严格：凡不符合下表的功能码，一律回 999，并记日志/事件：当前状态、盘内视野序号、收到的功能码）
状态：IDLE（主程序刚启动）→ WAIT_COARSE / WAIT_FINE / WAIT_PICK → DONE（回过 9）或 TOOL_CHANGE（回过 10）。DONE 与 TOOL_CHANGE 下任何请求都回 999（之后由 PLC 重新初始化 → 父程序重启主程序）。
术语：**粗定位** = 在扫描视野位置拍照（现有扫描路径的视野中心）；**精定位** = 把某个目标的挑取点对到相机主点下方后再拍。精定位相机坐标：XY = 粗拍模组 XY + (目标挑取点的工作面坐标 − 主点射线与工作面交点坐标)，Z = 扫描 Z。用主点（标定内参的 cx,cy），不是图像几何中心。

1. IDLE 收 1 → 进入工作模式：回 1 + 第 1 个视野粗定位坐标 → WAIT_COARSE。（IDLE 收 100/101 走现有对刀分支；IDLE 收 20/60 → 999。）
2. WAIT_COARSE 收 20 → 到位校验（40911-15 对比下发坐标，超公差 999，沿用现有）→ 拍照 → 全量识别（现有 12 步检测 + 挑取门 + 负责区 OTHER + 针区屏蔽，不变）。
   - "可去"= 门通过、在本视野负责区内、且**不是已尝试过的目标**。已尝试 = 与本盘已尝试名单（模组坐标）按现有匹配半径匹配上 → 标红框，不可去。
   - 写 40941 = 本次粗拍的可去数量（每次粗拍都写，和应答一起、在写 40934 之前写）。
   - 本视野第一次粗拍时记 N0 = 该可去数量；本视野允许尝试次数 = ceil(cap_ratio × N0)（cap_ratio 默认 1.2）。N0 只在首拍记，后续粗拍不改。
   - 若本次粗拍是"上限已到后的最终检查"或可去数量为 0 → **离开视野**（见第 5 条）。
   - 否则：按现有优先级（物理面积降序）取前 max_fine_targets（默认 10）个可去目标作本轮名单，算各自精定位相机坐标，回 1 + 名单第 1 个的精定位坐标 → WAIT_FINE。
3. WAIT_FINE 收 20 → 到位校验 → 拍照 → 全量识别 → 精定位判定：
   - 精定位框 = 以主点在工作面投影为中心、边长 2×fine_box_half_mm（默认 4.0mm，可配）的模组坐标正方形（物理意义：框内深度视差 < 0.1mm，半宽≈0.1×物距/2.5mm，写进 design.md）。
   - 候选 = 门通过、未被已尝试名单匹配、与框有交集的目标；对每个候选，把它的掩膜/轮廓裁到框内，用一代同一取点方法（`_hair_pick_point` 一路，必要时复用 `_refine_pick_points` 的逻辑）在裁后的区域重新求挑取点；挑取点工作面坐标落在框内才算"可挑"。多个可挑候选按优先级取第一个。
   - 可挑 → 该目标加入已尝试名单（记精定位挑取点模组坐标，同时记粗定位时的坐标），本视野尝试次数 +1；按现有补偿公式分别算 **工具1 和 工具2** 的挑拣坐标，**两组同时写入** 40960-64 与 40966-70，然后 40934=3，最后 40933=Task_ID → WAIT_PICK。**删除 PC 端工具交替逻辑**（由 PLC 选工具）。占位标定拒发坐标的守卫保留。
   - 不可挑（框内无候选 / 挑取点落不进框 / 框内目标门不通过）→ 把本轮名单当前这个粗定位目标加入已尝试名单（原因记录：fine_empty / fine_point_outside / fine_rejected），本视野尝试次数 +1，**放弃本轮剩余名单**，回 1 + 当前视野粗定位坐标 → WAIT_COARSE。
4. WAIT_PICK 收 60 →
   - 若本视野尝试次数 ≥ 允许次数 → 回 1 + 当前视野粗定位坐标，并标记下一次粗拍为"最终检查" → WAIT_COARSE。
   - 否则若本轮名单还有下一个 → 回 1 + 下一个的精定位坐标 → WAIT_FINE。
   - 否则 → 回 1 + 当前视野粗定位坐标 → WAIT_COARSE。
   - 不再做"每挑一次回原位重拍判成败"：成败在下一次粗拍判——已尝试目标被再看到 = 失败（红框），没看到 = 成功。
5. 离开视野（在 WAIT_COARSE 收 20 的应答里决定）：
   - 换工具判定：若本视野尝试次数 ≥ tool_check_min_attempts（默认 3）且（本次粗拍红框数 + 本次可去数）> tool_check_ratio（默认 0.5）× N0 → 回 **10** → TOOL_CHANGE。
   - 否则有下一视野 → 回 1 + 下一视野粗定位坐标 → WAIT_COARSE（新视野重新记 N0/尝试次数）。
   - 否则 → 回 **9** → DONE。
   - 守卫：单视野粗拍次数超过 max_coarse_shots_per_view（默认 30）→ 强制离开视野（同样先做换工具判定），记 WARNING 事件。
6. 所有新参数进 `config/nest_clear.yaml` 并做 schema 校验（缺项/类型/范围错立即报错）：max_fine_targets、fine_box_half_mm、cap_ratio、tool_check_min_attempts、tool_check_ratio、max_coarse_shots_per_view。
7. 画面：粗拍叠加图沿用 绿=可去、黄=门拒、红=已尝试（被再看到）、灰=OTHER；本轮名单在粗拍图上标序号。精定位叠加图画出精定位框、选中目标、裁后的新挑取点；文件名区分 coarse/fine。
