# 通信联调模式移除盘点

| 类别 | 盘点及处理 |
|---|---|
| A 假行为 | 假世界、随机种子与场景、假坐标、影子检测替换、假点标注、专用应答标识、红条和日报标记，以及专用记录与配置目录均移除；真实流程按实际结果结束。 |
| B 真实功能 | 自动选择唯一相机、80 标定（起始位置、实际行程与原图）、90/95 工具偏移、150 精度标定、预览、曝光和白平衡保留在生产路径；100 换针对刀及基准功能继续走真实代码。 |
| C 设备参数 | 相机、行程、扫描和标定参数合并至生产配置，见下表；PLC 参数、预览、工具偏移与精度参数两边相同。标定产物统一使用 config/calibration，运行记录使用 runs。 |
| D 上线前待补 | 仓库相机标定、工具补偿和两把工具基准仍是占位；必须迁入有效现场产物或重新标定。占位相机标定仍禁止下发挑取坐标。扫描角点与步距来自联调设置，需现场核实是否覆盖实际料盘：按名义视野 94.97×71.65 mm，Y 步距 70 mm 仅重叠约 1.65 mm，低于配置的 20 mm 最小重叠要求；必须测量并修正扫描方案。挑毛使用真实 hair 算法，未发现外部模型依赖；检测参数和实际效果需现场验证。 |

| 配置项 | 原生产值 | 采用值与原因 |
|---|---|---|
| scan.mode、corners、step | tray、占位角点、10/10 | corners，(160,0)/(100,0)/(160,140)，60/70，沿用设备设置，须核实覆盖范围 |
| travel XYZ | 各轴 ±500 | X 80–180、Y -10–150、Z -15–0，设备实际行程；原挑毛测试 Z=0 不是设备行程 |
| camera SN、曝光、增益、白平衡 | 待填写、未设置 | auto、6000 µs、0 dB、[2.4219,1,1.5078]；自动选择要求恰好一台相机 |
| camera_calibration 起始位 | null | [92.651,88.445,-11.904]，现场实测 |
| 标定板厚、XY/Z 限制、网格、Z 层 | 3、25/5、20、5/2.5 mm | 板厚 3.15 mm（11-22 实测真实标定板），12.5/3、12、3/1.5 mm 沿用现场行程设置；旧测试纸板厚度为 0.1 mm |
| 饱和比例 | 0.01 | 0.02，现场光照设置；其余亮斑与精度阈值相同 |
| tool_calibration.enabled | true | true；旧测试配置 false 是禁用功能，不是设备测量值 |
| supervisor 命令 | python 默认配置 | .venv/bin/python，显式指定生产配置 |
| 标定和记录目录 | 生产目录 | 保持生产目录；旧目录不再使用 |

旧配置的 run_mode: commtest 会明确报错。现场迁移顺序见 [设备迁移](deploy_after_commtest_removal.md)。
