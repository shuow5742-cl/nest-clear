# 本地针尖标注工具

此工具在本机运行，不需要联网或登录。需要系统 Python 3、tkinter 和 Pillow。打开终端，在仓库目录执行：

```bash
/usr/bin/python3 tools/tip_annotator/annotate.py /图片目录
```

程序递归寻找 PNG，左侧圆圈表示尚未保存，勾表示已保存。选择图片或使用左右方向键切换；修改后切图和关闭窗口会自动保存，也可按 Ctrl+S 保存。原图不会被修改。

先用 1、2、3 选择黑胶、针身、针尖，分别用画笔（B）涂抹。画笔尺寸按图像像素计，用 `[ ]` 调整；橡皮（E）擦除。多边形（P）单击添加顶点，双击或回车填充，Esc 取消。阈值辅助开启后，画笔和多边形只填入灰度不超过滑条设定值的像素；橡皮不受阈值限制。透明度滑条和 H 控制叠加显示。Ctrl+Z 撤销、Ctrl+Y 重做；至少保留 30 步掩膜修改。

滚轮以鼠标位置为中心缩放，中键或右键拖动平移，点击“适应窗口”恢复全图。状态栏显示图像坐标、灰度和推导结果。需要人工点选时按 T，再在图上单击；“清除人工点”可以删除它。人工点与自动推导点分别保存。相邻五帧画面相同时，可先切到后一张，再点击“复制上一张标注到本张”；图片尺寸须一致。

“清除当前类别”经确认后清除本张选中类别的标注，保留人工点，可撤销。
“清除本张全部”经确认后清除所有类别和人工点，可一并撤销恢复。

针身掩膜全部像素的主成分方向确定中轴线，方向朝向针尖掩膜的中心。将针尖像素投影到该方向，取最远像素，再将它投影到中轴线上，得到定义中的工具尖。黄色虚线是中轴线，青色圆圈是最远针尖像素，黄色十字是推导工具尖，粉色十字是人工点。针身或针尖缺失时状态栏提示“缺少标注”；针身太少或没有明确方向时不能推导。请检查针身和针尖是否标完整，尤其是细齿。

标注保存在每张原图旁的 `annotations/` 目录：`图片名.labels.png` 为单通道标签（0 背景、1 黑胶、2 针身、3 针尖），`图片名.json` 保存像素数、中轴线、最远针尖、推导工具尖、人工点、阈值设置和保存时间。重新打开会自动加载。
