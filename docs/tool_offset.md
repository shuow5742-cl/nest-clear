# 工具偏移标定现场操作说明

适用流程：主相机多视角三角定位固定标定尖 + 双对刀相机全自动姿态测量与对准（`40905 = 1`）。  
旧版菲林片点动对准流程（功能码 `95` / 界面手动选工具及"工具到位"确认）已整体废弃。

---

## 1. 准备工作

1. **主相机已完成标定**：`camera.yaml` 非占位文件且存在有效内参与外参（含非远心倾斜外参）。
2. **标定尖就位与照明**：对刀站前方固定锥形标定尖干净无遮挡，主相机白/灰底照明均匀，正/侧对刀相机背光清晰。
3. **无须界面选工具**：待标定工具编号完全由 PLC 通过 `100`（工具 1）或 `110`（工具 2）指定。
4. **全自动运行**：整个标定过程无需人工点动确认；界面仅保留 **【放弃本次标定】** 按钮，触发后算法将在下一个 PLC 请求直接回 `99` 退出。

---

## 2. 新协议通信与交互流程

所有工具偏移标定请求均须携带 **`40905 = 1`**（`40905 = 2` 为换针对刀，不在本流程内）。每次 `90`–`131` 应答时，PC 均同步在 `40935` 回写本次读到的 `40905`。

### 步骤 1：主相机三角定位标定尖（`90 → 91`）
1. PLC 将主相机移至对刀站上方初始视角，写入 **`40904 = 90`**、**`40905 = 1`** 并更新 `Task_ID`（`40903`）。
2. 算法稳定采样实时坐标（`0.5 s` / `6` 次极差 `≤ 0.02 mm` 取均值），连续拍摄 3 帧主相机图像识别标定尖，取三帧中位像素结合 `camera.yaml` 形成该视角三维视线。
3. 若视角数不足或需继续补拍（默认需至少 3 个视角，质量不足最多补至 5 个）：
   - 算法基于首点仅向 `X+` 与 `±Y` 规划下一拍照点（基线 `20–30 mm`、不超行程与可去范围 `X ≥ 第1点 X`、保证标定尖预测落在画面中央 80% 内），将下一相机坐标写入 **`40942–40946`** 并回 **`90`**；
   - PLC 移到位后再次下发 **`90`**（新 `Task_ID`）。
4. 当交点最大射线残差 `≤ 0.02 mm` 且最大基线/距离比 `≥ 0.15` 时，三角定位完成，算法回 **`91`**，算出与生产 `calculate_pick_coords` 完全一致的标定尖目标机台 XY。

### 步骤 2：对刀相机测姿态与自动对准（`100/110 → 111/121`）
1. PLC 将工具 1 或工具 2 移入两台对刀相机视野正上方安全间隙处，发 **`100`（工具 1）** 或 **`110`（工具 2）**（`40905 = 1`）。
2. 首次请求稳定记录初始位置 **`P0`**，正/侧相机各采 5 帧同时识别 **工具尖（Trident 五帧中位）** 与 **底部标定尖（五帧中位）**；任一识别失败直接回 `99`。
3. **每次标定现测相机雅可比（不复用旧值）**：依次相对 `P0` 下发 `X+0.2`、`Y+0.2`、`Z+2.0`、`Z-2.0` mm（写入 `40948–40952` / `40954–40958` 并回 `100/110`，Z 步长不超过 `2 mm`），拟合 `front`/`side` 各自 `2×3` 雅可比 `J`。
4. **水平对准与防撞**：
   - 在 `front` 视图解 `r - p = J_x·Δx + J_z·Δz`，在 `side` 视图解 `r - p = J_y·Δy + J_z·Δz`；
   - **每次下发目标前先做防撞预测**：用 Z 雅可比计算当前与移动后的竖直间隙；若预测间隙 **`< 1.0 mm`**，立即禁止下发并回 **`99`**（`"会碰到标定尖"`）；
   - 当 `|Δx| ≤ 0.05 mm` 且 `|Δy| ≤ 0.05 mm` 时判定对准，读取稳定实时坐标 `P_final`，计算 `offset_xy = P_final_xy - target_xy`，回 **`111`（工具 1）** 或 **`121`（工具 2）**；否则 XY 限幅单步 `≤ 0.5 mm`、累计相对 `P0 ≤ 3.0 mm` 下发移动，最多 10 轮。

### 步骤 3：130 最终坐标核对与保存（`130 → 130`）
1. PLC 将完成时的工具坐标写入 **`40917–40921`（工具 1）** 或 **`40923–40927`（工具 2）**，发送 **`130`**（`40905 = 1`）。
2. 算法逐轴核对读回坐标与 `P_final` 的差值，全部 `≤ 0.05 mm` 时：**先保存** `tool_offset.yaml`（带 `history/` 备份及 `baseline_stale: true` 标记）并同步更新 `tools.yaml` 对应工具的 XY（Z 保持不变），再回 **`130`**。
3. 核对超差或写入失败则回 **`99`**，不覆盖已有标定。

### 步骤 4：连续标定另一把工具
完成工具 1 后如需紧接着标定工具 2，PLC 必须从 **`90`**（`40905 = 1`）重新发起新会话（重新执行主相机三角定位与工具姿态测量）。

## 3. 功能码与应答速查表

| PLC 请求 (`40904`) | 条件 / `40905` | 算法正常应答 (`40934`) | 写入坐标区 | 异常应答 |
|---|---|---|---|---|
| `90` | `40905 = 1`（空闲态发起 / 会话中续拍） | `90`（需继续移动）或 `91`（三角定位完成） | `40942–40946` | `99`（检测/规划/残差超限）；`999`（缺 `camera.yaml` 或 `40905 ≠ 1`） |
| `100` | `40905 = 1`（须在 90 会话内） | `100`（探测/对准）或 `111`（工具 1 对准完成） | `40948–40952` | `99`（碰撞/识别/收敛超限/放弃）；`999`（90 会话外或挑毛中） |
| `110` | `40905 = 1`（须在 90 会话内） | `110`（探测/对准）或 `121`（工具 2 对准完成） | `40954–40958` | 同上 |
| `130` | `40905 = 1`（须已回 `111/121`） | `130`（核对一致且已先保存） | `40917–40921` / `40923–40927`（PLC 写，PC 核对） | `99`（三轴核对差 `> 0.05 mm` 等）；`999`（会话外） |
| `100` / `110` | `40905 = 2`（换针对刀） | `100/110` 或 `111/121` | `40948–40952` / `40954–40958` | **`999`**（预测间隙 `< 1.0 mm`，提示`"会碰到标定尖"`）；`131`（未识别标定尖等） |

## 4. 常见失败现象、错误码与排查

| 应答 | 界面/日志典型错误 | 位置与常见原因 | 现场排查建议 |
|---|---|---|---|
| `99` | `主相机未识别到标定尖` / `候选不唯一` | 主相机第 `n` 张照片 | 检查标定尖顶光背景是否过暗/存在杂物或高反光斑，确认处于画面内。 |
| `99` | `无法规划满足行程、X≥首点且标定尖在画面中央80%的下一拍照坐标` | 视角规划阶段 | 第 1 张 `90` 拍摄位置距行程上限或视野边缘过近，调整 PLC 初始 `90` 拍照点。 |
| `99` | `三角定位已采集 5 个视角仍不满足质量门限` | `max_residual_mm > 0.02` 或基线比不足 | 复核 `camera.yaml` 标定精度、检查采集前模组是否完全停稳。 |
| `99` | `未识别到对刀标定尖` / `工具尖不可靠` | `front`/`side` 对刀相机 | 擦拭标定尖、检查背光源亮度及工具/标定尖是否均在视野内。 |
| `99` / `999` | `会碰到标定尖` | 防撞安全门限（预测间隙 `< 1.0 mm`） | 抬高工具进入视野的 Z 高度，或核查当前工具装夹伸出长度。 |
| `99` | `对准超过最大轮次 10 仍未收敛` / `累计位移超过 3 mm` | `100/110` 对准循环 | 核对初偏是否过大或模组机械背隙、相机固定支架是否松动。 |
| `99` | `130 最终坐标核对不一致` | `40917–40927` 核对阶段 | 检查 PLC 在收到 `111/121` 后是否误移动了工具或写入寄存器号有误。 |
| `999` | `未收到 90 却收到工具偏移标定请求` | 请求分发 / `40905` | 每次标定工具 1 或工具 2 之前均须先由 PLC 发 `90`（`40905 = 1`）。 |
