# 工具偏移标定现场操作

1. 完成主相机标定，核对起始坐标、设备行程、相机光照及 `tool_offset.card_thickness_mm`。将菲林片平整固定在料盘面，打印选择实际大小，标定过程中不要移动卡片。
2. PLC 空闲时发送 90，打开“工具偏移标定”页，选择工具1或工具2、仅中心或中心+边缘验证，再按“开始”。PLC 按返回坐标移动并在到位后发 95。总览照识别后按 PLC 时序继续。
3. 界面提示“请手动移动工具…到 Txx 中心”时，点动所选工具，使针尖对准标注目标中心，停稳后按“工具到位”。观察图中圆环、十字及放大图；未提示时不要移动工具。边缘验证只移动相机，不需要移动工具。
4. 离群点会剔除并排队重测。界面出现覆盖确认时核对旧结果、新结果、差值和当前工具补偿；按“覆盖保存”才会保存并更新该工具 XY，Z 保持原值。按“不保存”或“放弃本次标定”结束本次标定。
5. 保存后需为该工具重建对刀基准，再执行换针对刀。相机标定变更后应重新检查工具偏移。

“未找到标定卡”：检查卡片是否在视野内、平整摆放和光照；“尺寸不符”：检查打印机是否按实际大小打印；“目标识别质量差”：检查墨迹、卡片、光源和对焦；“多点不一致”：检查人工对准、卡片固定和震动。若提示轴还在动或抖动过大，等待停稳后重新按“工具到位”。到位超差或错序 999 时检查 PLC 请求顺序和坐标，再重新开始会话。联调结果独立保存，不是生产结果。
