# 主流程测试模式（菲林片）

完成相机标定和两把工具的工具偏移标定后，将菲林片置于料盘面。主程序空闲或未运行时，在主页点击“主流程测试模式（菲林片）”开关。顶部红色提示条表示模式开启。每盘开始时读取模式，本盘固定；盘结束并空闲后再次点击可关闭。按正常 PLC 自动模式和循环启动流程运行，结束后关闭模式，再进行真实挑毛。

粗拍与精定位都识别整幅图中的 ArUco 和圆环，精定位在工作框内匹配同编号目标。屏蔽区、视野责任区和已尝试目标过滤与正式主流程一致。默认 T03、T06、T09、T12、T15、T18、T21、T24、T27、T30（编号为 3 的倍数）不可去，可在配置 `test_mode.non_pickable` 修改。标注图绿色为可去、橙色为不可去、红色为挑取失败且不再去、蓝色为够不着、白色粗框为本次下发目标。进度区显示可去、不可去、已下发和失败数量。失败目标本盘不会再次下发，相邻视野按模组坐标去重。测试模式不执行换工具判定（菲林目标挑不起来），其余与正式流程一致，包括粗拍、复核和次数上限。扫描位到位监督也共用正式流程：等待坐标稳定后使用均值；超差或超时未稳定只记录告警并继续。

菲林表面高度按料盘面加 `tool_offset.card_thickness_mm` 换算，与工具偏移标定使用同一平面处理。两把工具的 XY 分别使用现有补偿；Z 分别来自 `config/calibration/tool_offset.yaml` 中对应工具 `samples` 的每次人工对准 `tool_xyz_mm[2]` 最大值，包括离群样本。若任一工具缺少完整有效样本，系统拒绝坐标并按异常应答；请完成对应工具的工具偏移标定。两个工具坐标均经过行程检查。

事件记录模式变化、每盘使用模式、换针判定及实际提交的目标、双工具坐标和各自 Z 样本数与最大值。状态文件位于 `runs/state/film_mode.json`（具体根目录取 `record.directory`）。

扫描拍照高度为 Z=-3。精定位相机或任一工具的目标坐标超出行程时，目标自动标为够不着（蓝），不会下发。XY 保留 0.2 mm 余量，Z 使用行程闭区间；可达范围随工具偏移和补偿自动计算。
